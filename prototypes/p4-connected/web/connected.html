Prototype (release-2 spike P4). Not part of release 1. Optional, read-only checks against your own tenant. The offline assistant works without this page.

Connected checks

1. Your app registration

Use the single-tenant app registration that your administrator created in your own tenant (platform: Single-page application, redirect URI http://localhost/redirect.html, no secret). This page has no built-in client ID.

The IDs stay in this tab's memory. They are never written to the evidence note; the alias is used instead.

2. What this page will read

Signing in asks Microsoft Entra for these delegated, read-only Microsoft Graph permissions. A tenant administrator must have granted consent for them on the app registration. Your own account also needs a supported Entra role (for example Security Reader).

Data it reads, keeps and exports

    
    
      
  • Reads: incident titles, severity, status, creation time and portal link host; for each alert only the product fields (serviceSource, detectionSource, productName). Graph also returns alert details and entity evidence (device names, IP addresses, accounts); the page discards them as soon as they arrive. The hunting query returns counts per table and provider only.
    • 
      
  • Keeps: results and tokens in this tab's memory only. Nothing is written to browser storage, cookies or disk. Closing or reloading the tab forgets everything.
    • 
      
  • Exports: only when you click Export evidence note, a JSON file with counts and short findings that you can preview first. Incident titles are excluded unless you tick the option. Tenant ID, client ID, account names and tokens are never exported.
    • 
    

    
What it never does

    
    
      
  • It cannot create, update, assign, close or delete anything: it requests no write permission, and its code refuses any request other than the two above.
    • 
      
  • It sends nothing anywhere except login.microsoftonline.com and graph.microsoft.com (enforced by the browser's Content-Security-Policy). No telemetry.
